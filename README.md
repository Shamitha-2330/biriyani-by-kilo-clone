# Biriyani By Kilo Home Page (Recreation)

A static front-end recreation of the Biriyani By Kilo home page, built with HTML and CSS to practise hero sections, image layouts and typography.

> Recreation built for learning and practice. Not affiliated with Biriyani By Kilo.

## Screenshot

![Biriyani By Kilo home page](screenshots/home.png)

## About

This project recreates the Biriyani By Kilo home page as a desktop layout. It focuses on visual design and page structure only. There is no ordering system or backend.

## Tech Stack

- HTML5
- CSS3

## What I Practised

- Building an image-led hero section
- Laying out menu and offer sections with Flexbox and CSS Grid
- Working with fonts, spacing and colour to match a brand style
- Structuring a long landing page into clear sections

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Shamitha-2330/biriyani-by-kilo-homepage.git
   ```
2. Open `index.html` in any browser, or use the Live Server extension in VS Code.

## Known Limitations

- Static page with no interactive features
